# Bundled documentation — index

1612 pages of Frappe's official documentation, exactly as published. 1607 were fetched 2026-08-31; 5 newer pages (Automations, the new BOM Creator) were added 2026-11-14.

## How to find a page

- **From a capability:** every adapter row names its page, e.g. `docs/erpnext/erpnext__sales-invoice.md`.
- **From a topic not in this plugin's capability list:** search this index, or search the `docs/` folder by filename. Filenames are the live URL path with `/` replaced by `__`, and any character outside letters, digits, `.`, `_` or `-` replaced by `-`.
- Each file's front matter carries its `title`, live `url` and the date Frappe last `updated` it.

## What is not bundled

- **Screenshots.** The pages reference images on Frappe's servers; those URLs need internet. Where a step is only a picture, say so rather than inventing what it shows.
- **Links between pages** inside these files are live URLs (`/erpnext/credit-note`). Offline, translate them to a filename with the rule above.
- **Legacy version manuals** (ERPNext v12–v14, Framework v13–v15) were deliberately excluded: this plugin targets v16 with a v15 fallback.
