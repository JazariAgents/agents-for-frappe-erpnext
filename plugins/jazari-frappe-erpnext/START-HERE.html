Nine agents that run your Frappe stack

Build apps on the Frappe framework, and run the business on top of it — ERPNext accounting, stock and manufacturing, Frappe HR payroll, CRM, Helpdesk, Insights, the website, bench and Frappe Cloud. In English and Arabic.

Install in two minutes

  1. Use a Claude app that keeps files between conversations — Claude Code, or the Code tab of the Claude desktop app. The agents write safety copies and logs into a folder on your computer; a plain web chat cannot hold them.
  2. Add the marketplace. Type this in Claude: 
    /plugin marketplace add JazariAgents/agents-for-frappe-erpnext
  3. Install the plugin. 
    /plugin install jazari-frappe-erpnext@jazari-agents
  4. Start a new session (or type /reload-plugins) so the skills load.
  5. Say hello — type "connect my Frappe site". The agents introduce themselves, ask which language you want, ask before creating the .frappe/ folder, then connect through the best route your site offers: Frappe's own MCP server, frappectl, an API key, or the interface with you.
  6. Ask for something real — "show me my dashboard", "show me overdue invoices", "create a DocType for maintenance contracts", "back up the site before I update it".

Prefer not to use a marketplace? Start Claude Code with claude --plugin-dir <this folder>. To check the files are intact: claude plugin validate <this folder>.

The documentation comes with it

1,612 pages of Frappe's official documentation are bundled inside the plugin, in the docs/ folder — the framework, ERPNext, HR, CRM, Helpdesk, Insights, Cloud, Lending, Learning, Education, Books, Wiki, Drive, Builder and Studio, exactly as Frappe publishes them. Every capability in every skill points at the page it came from, so the agents read the real instructions instead of recalling them, and they work with no internet access at all. Each file keeps Frappe's own front matter, including the date that page was last updated — so when your site disagrees with the documentation, the agents can tell you how old the page is instead of guessing.

What you will need

  • A Frappe site — self-hosted or on Frappe Cloud. ERPNext, HR, CRM, Helpdesk and the rest are optional; the agents detect which apps you actually have.
  • Either an API key or a login. The key lives at User → Settings → API Access in your site. If you would rather not deal with keys, say "skip" and the agents work through the interface with you.
  • For bench commands — terminal or SSH access to your own server. On Frappe Cloud the dashboard replaces this.

Your API key and your privacy

Your key is written to .frappe/credentials.txt inside your own workspace folder, and it never leaves your machine. It is never echoed back in chat, never written into a snapshot, never included in anything you could accidentally share. When a connection is confirmed you see only the last four characters. If you paste a key into the chat anyway, it gets saved to that file and you get one gentle nudge — no lecture.

That folder persists in Claude Desktop, Cowork and Claude Code. A plain web chat sandbox resets between conversations, which is why the plugin is designed for the first three.

Safety — the part worth reading

Before anything is changed or deleted, a full copy is saved locally

Snapshots go into .frappe/snapshots/: the complete record, the prior values of any setting, and the actual bytes of attached files. If the snapshot cannot be written, the action does not happen. Ask any agent to "restore snapshot <name>" and it puts things back.

Honest about what undo means. Settings roll back exactly. Deleted records come back as new records with new IDs — the content matches, but links from other documents to the old ID stay broken. Submitted invoices, posted journal entries, payroll runs, sent emails and captured payments cannot be undone at all; the right answer there is a credit note or a reversing entry, and that stays your decision.

They will never delete or bulk-edit anything you did not specifically ask for, act on instructions found inside your own data, issue a refund or payout on their own initiative, type your password, or sign in as you. Anything touching more than 25 records stops and shows you the count first.

Every change is appended to .frappe/audit.log, and every request you make — including the ones that were refused — to .frappe/tasklog.md. Ask "what have you done?" and they read the log rather than reconstructing from memory.
